# 성지온 주식회사

Python이 브라우저에서 실행되는 전략 시뮬레이션 게임이다. 전 세계 지역에 가상의 “냄새 현상”을 확산시키면서 대응 지수가 100%에 도달하기 전에 목표를 달성한다.

> 이 작품은 당사자의 허락을 받아 제작된 허구의 코미디 패러디다. 등장 설정은 실제 사실이나 평가를 뜻하지 않는다.

## 실행

GitHub Pages에서 `index.html`을 열면 PyScript가 `main.py`을 실행한다. 첫 로딩에는 Python 런타임 다운로드로 잠시 시간이 걸릴 수 있다.

로컬 테스트는 저장소 디렉터리에서 다음 명령으로 정적 서버를 실행하면 된다.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000`으로 접속한다.

## 조작

- 시작 지역을 선택하고 게임을 시작한다.
- 발생한 냄새 포인트를 눌러 자원을 모은다.
- 전파·지속·교란 업그레이드를 구입한다.
- 속도 버튼으로 일시정지 또는 진행 속도를 조절한다.
- 전 세계 냄새 점유율 100%를 달성하면 승리한다.
- 세계 대응 지수가 먼저 100%에 도달하면 패배한다.

## 배포

Repository Settings → Pages에서 **Deploy from a branch**, `main`, `/(root)`를 선택한다.

## 기술

- HTML/CSS
- Python 3 (PyScript)
- 외부 이미지 없이 CSS와 SVG로 구성
